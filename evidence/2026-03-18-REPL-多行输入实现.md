## 实现内容

### 1. 核心算法：Lexer-based 括号计数法

```typescript
function isComplete(src: string): boolean {
  try {
    const tokens = lex(src)
    let depth = 0
    for (const token of tokens) {
      if (token.type === TT.LBRACE || token.type === TT.LBRACKET || token.type === TT.LPAREN) {
        depth++
      } else if (token.type === TT.RBRACE || token.type === TT.RBRACKET || token.type === TT.RPAREN) {
        depth--
      }
    }
    return depth === 0
  } catch (e) {
    return false // lex error 表示输入不完整
  }
}
```

**原理**：
- 统计 `{[(` vs `}])` 的平衡性
- 平衡（depth = 0）→ 尝试解析执行
- 不平衡 → 继续累积输入
- Lex 错误 → 输入不完整（如未闭合字符串）

### 3. 支持的多行结构

✅ **类定义**
```n
class Animal {
  constructor(name) {
    this.name = name
  }
}
```

✅ **函数定义**
```n
fn add(a, b) {
  return a + b
}
```

✅ **控制流**
```n
if x > 5 {
  print("yes")
} else {
  print("no")
}
```

✅ **嵌套结构**
```n
fn outer() {
  let inner = fn() {
    return { a: [1, 2, 3] }
  }
  return inner()
}
```

✅ **多行对象/数组**
```n
let obj = {
  name: "test",
  value: 42
}

let arr = [
  1, 2, 3,
  4, 5, 6
]
```

## 技术亮点

1. **零侵入性**：不修改 parser 和 interpreter，仅在 REPL 层实现
2. **高可靠性**：利用 lexer 的 token 流进行精确检测
3. **用户友好**：提示符自动切换，符合 Node.js/Python REPL 习惯
4. **边界清晰**：通过 lex 错误捕获未闭合字符串等异常情况
