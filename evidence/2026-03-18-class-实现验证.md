## 实现内容

### 新增语法特性
1. **class 定义**：支持类定义语法
2. **constructor**：构造函数支持
3. **extends**：单继承支持
4. **super()**：父类构造函数调用
5. **this**：实例引用
6. **new**：实例化操作符

### 修改文件
- `src/lexer.ts`：新增 5 个关键字（class, extends, new, super, this）
- `src/ast.ts`：新增 Class 和 New 节点类型
- `src/parser.ts`：实现 class 语法解析
- `src/interpreter.ts`：实现类执行逻辑（NClass, NInstance, 继承链）

### 关键实现细节
1. **继承链查找**：`findMethod()` 函数沿继承链查找方法
2. **this 绑定**：在构造函数和方法调用时自动绑定 this
3. **super 机制**：通过 `__class__` 隐藏变量追踪当前类，支持多层继承
4. **原型污染修复**：使用 `Object.create(null)` 避免 KW 映射的原型链问题

## 测试用例

### 1. 基础类定义和实例化
```n
class Animal {
  constructor(name, sound) {
    this.name = name
    this.sound = sound
  }
  speak() {
    print(this.name + " says " + this.sound)
  }
}

let cat = new Animal("Kitty", "meow")
cat.speak()  // Kitty says meow
```

### 2. 单继承
```n
class Dog extends Animal {
  constructor(name) {
    super(name, "woof")
  }
  fetch(item) {
    print(this.name + " fetches " + item)
  }
}

let rex = new Dog("Rex")
rex.speak()       // Rex says woof
rex.fetch("ball") // Rex fetches ball
```

### 3. 多层继承
```n
class Robot {
  constructor(id) {
    this.id = id
  }
  beep() {
    print("Robot " + str(this.id) + " beeps")
  }
}

class SmartRobot extends Robot {
  constructor(id, name) {
    super(id)
    this.name = name
  }
  greet() {
    print("Hello, I am " + this.name)
  }
}

class SuperRobot extends SmartRobot {
  constructor(id, name, power) {
    super(id, name)
    this.power = power
  }
  showPower() {
    print(this.name + " has power level " + str(this.power))
  }
}

let bot = new SuperRobot(42, "Optimus", 9000)
bot.beep()      // Robot 42 beeps
bot.greet()     // Hello, I am Optimus
bot.showPower() // Optimus has power level 9000
```
