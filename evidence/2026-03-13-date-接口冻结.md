## 首版支持范围
### 构造入口
- `Date()`：返回当前时间对应的日期对象。
- `Date(string)`：按宿主 JavaScript `Date` 解析字符串。
- `Date(number)`：按毫秒时间戳创建日期对象。

### 静态方法
- `Date.now()`：返回当前毫秒时间戳。
- `Date.parse(string)`：返回毫秒时间戳；若解析失败，首版建议返回 `NaN`，与宿主一致。

### 实例属性
- `date.timestamp`
- `date.year`
- `date.month`
- `date.day`
- `date.hours`
- `date.minutes`
- `date.seconds`

属性语义：
- `month` 按自然月返回 `1-12`，不要直接暴露宿主 `0-11`。
- 其他字段沿用宿主本地时区读取语义，首版不做时区抽象。

### 实例方法
- `date.format()`：返回 ISO 8601 字符串。
- `date.toString()`：返回宿主默认日期字符串。
- `date.getTime()`：返回毫秒时间戳。
- `date.getFullYear()`
- `date.getMonth()`：返回 `1-12`。
- `date.getDate()`
- `date.getHours()`
- `date.getMinutes()`
- `date.getSeconds()`
- `date.addDays(number)`：在当前对象基础上增加天数，并返回对象本身。

## 类型与运算语义
- `typeof Date(...) === "date"`
- `date1 == date2` 与 `date1 != date2`：按毫秒时间戳比较，不按对象引用比较。
- `date1 < date2`、`date1 > date2`、`date1 <= date2`、`date1 >= date2`：按毫秒时间戳比较。
- `date1 - date2`：返回毫秒差值。
- 首版不支持 `date + number`、`date - number`、`date + date`。

## 错误与边界
- 传入不支持的参数类型时抛出明确错误，例如 `Date(true)`。
- 对无效日期字符串：
  - 如果内部创建后为 `Invalid Date`，建议在构造阶段直接抛错，避免后续传播隐式坏值。
- 首版不支持时区显式转换、UTC 专用构造、格式化模板。

## 示例用法
```n
let now = Date()
print(typeof now)
print(now.timestamp)
print(now.format())

let a = Date("2026-03-13T00:00:00Z")
let b = Date("2026-03-14T00:00:00Z")
print(a < b)
print(b - a)

let c = Date(Date.now())
print(c.year)
print(c.month)
print(c.day)

let d = Date("2026-03-13T08:00:00Z")
d.addDays(2)
print(d.format())
```

## 风险
- 当前语言没有 `new` 与宿主对象抽象，`Date` 需要通过内置入口特殊处理。
- 若后续要支持时区、UTC 构造、格式模板，建议二期单独扩展，避免首版接口反复变动。
